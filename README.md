# Paddock · Tienda de réplicas de Fórmula 1

**Integrantes:** Fernando Moreno Ramos y Alejandro Delgado Toledano

## Descripción
Tienda web de varias páginas (inicio, catálogo, ficha de producto y contacto) con réplicas 1:18 de seis monoplazas de F1. Estilos escritos en SCSS modular con metodología BEM.

## Reparto de tareas

Alejandro:producto.html, contacto.html, scss abstract (funciones y mixins), base(reset), layout(footer y header)
Fernando: catalogo.html, index.html, scss abstract(variables), components(buttons y card), layout(sections)
Los dosh:imagenes, css, js, readme.md y gitignore
